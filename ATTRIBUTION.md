## Ink/Stitch fonts (`inkstitch/`)

131 embroidery fonts from the Ink/Stitch project's font collection,
https://github.com/inkstitch/embroidery-fonts (folder `src/`, commit `c7e3a05c3d6f5c77b881c50f257851af9a8e9cb8`), copied
unchanged: each folder keeps its own `LICENSE` file naming who digitized it, the typeface it
came from and its licence, and its `font.json` names the original font. Only the font data was
taken, none of Ink/Stitch's code.

Left out because their licences don't allow it here: the CC BY-NC-SA fonts (flowery_crosses,
flowery_multicolor, handkerchief, ladies_present, magic_crosses, nautical, priscilla,
very_crossy: non-commercial only), infinipicto (CC BY-ND: no derivatives), precious (GPL-3) and
nick_ainley (licence of the original unclear).
